# Состояние

В начале работы в ветке `MCUBoot` были созданы файлы `fw_update.c` и `fw_update.h` с нулевым статусом. Стенд уже возвращал Modbus после реального отката с `2.0.0` на `1.0.0`.

Подключены приём FC16, чтение состояния FC04, фоновое стирание Bank 2, запись, CRC32, пробная установка, подтверждение, откат и PC-клиент. Независимое ревью выявило расхождение в проверке размера файла и зависимость тайм-аута отката от TX. Обе ситуации покрыты проверками и исправлены. Проверен и повторный BEGIN после того, как загрузчик отверг новый образ и выставил image_ok в ещё пустом трейлере первичного слота.

В чистой сборке CubeIDE Debug из копии проекта сгенерирован ELF с `.isr_vector` по адресу `0x0800C200`. Штатные хостовые тесты завершились 665 успешными проверками, Python — 10 успешными тестами. Сохранение страницы калибровки проверено на модели Flash. Физический тест обновления по UART и замер планировщика предстоят после установки подписанной сборки с приёмником.

## CubeIDE Run с подписанным приложением

Обновление `1.1.0+0 → 1.1.1+0` подтверждено на плате через COM8. Для SWD добавлена подготовка подписанного HEX в Debug. Обе конфигурации запуска записывают только приложение с `0x0800C000` и запускают загрузчик с `0x08000000`.

Сборка STM32CubeIDE 2.0.0 и сверка содержимого HEX прошли с одноразовым ключом в отдельной копии. Проверены повторная сборка, отсутствие HEX для запуска после ошибки компиляции или подписи, ввод пароля для зашифрованного тестового ключа, отмена и неверный пароль. Диалог и запись через Run на реальной плате предстоит проверить.

## MCUboot с SHA-256

Оба проекта собраны штатной CubeIDE 2.0.0 в копии без `boot_public_key.h`. Загрузчик занимает 25 380 байт, BIN `1.1.3+0` — 47 388 байт. Проверены адреса векторов и одинаковое содержимое BIN и HEX до выравнивания. Хостовые тесты STM32 прошли 665 проверок, клиент UART — 14.

Реальный код `boot_go()` в модели Flash проверил запуск старого подписанного образа и нового SHA-256, обновление между ними, пробный запуск, подтверждение, откат и отказ при повреждённом хеше. Страница калибровки и область загрузчика в модели сохранились. На физической плате остаются однократная запись нового MCUboot через ST-Link и прогон обновления по UART.
