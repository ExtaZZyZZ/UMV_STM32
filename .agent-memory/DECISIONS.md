# Решения

## 19 ноября 2026. Стендовое обновление STM32 через UART

- Код STM32 и клиент ПК выполнены в рамках существующего проекта MCUboot. Договор об адресах статуса сохранён, новые поля идут вслед за первыми четырьмя. Генерация общей карты для Pi остаётся частью интеграции Pi.
- Для двух страниц трейлера зарезервировано по 2 КиБ. Стирание на прерываниях начинается с трейлера, запись образа разбита на короткие порции. Первые восемь байт образа записываются при INSTALL после CRC и проверки структуры. Это позволяет отличить частично принятый образ по стёртому заголовку после сброса.
- Используется совместимая с zlib поэтапная программная CRC32 с блоком 128 байт. Такой расчёт использует время нескольких проходов планировщика и обошёлся без добавления и настройки периферии CRC. Длительность прохода на плате ещё предстоит измерить.
- По тайм-ауту пробная загрузка сбрасывается независимо от работы передачи USART1. Для команд установки и отката ACK получает до 50 мс на отправку.
- Для первого прогона подходят два экземпляра одной Debug-сборки, подписанные отличимыми версиями. MCUboot привязан к уже установленному открытому ключу платы.

## 19 ноября 2026. Запуск из CubeIDE

Build Debug выпускает проверенный HEX для ST-Link через штатные `makefile.init` и `makefile.targets`. Версия образа отладки `1.1.2+0`. HEX для запуска появляется только после успешной сборки и проверки подписи. Повторная сборка без изменений может использовать ранее проверенный HEX. Пароль шифрования вводится в локальном диалоге при подготовке нового образа. Закрытый ключ остаётся зашифрованным, подпись сверяется с открытым ключом из проекта MCUboot.

## 19 ноября 2026. SHA-256 без ключей

По решению пользователя убрана подпись ECDSA в загрузчике MCUboot и упаковке приложения. SHA-256 проверяет целостность заголовка и полезной нагрузки. Подлинность автора прошивки больше не проверяется. Доступ к каналу обновления позволяет установить образ со своим хешем.

Сборка Debug упаковывает образ автоматически. BIN предназначен для UART и заканчивается на TLV. HEX для Run содержит те же байты, адрес первичного слота и выравнивание до 8 байт. Для перехода с подписанной прошивки на плате с подтверждённым основным образом достаточно обновить загрузчик через ST-Link. Старые исправные подписанные образы проходят проверку SHA-256.
