# Архитектура обновления

MCUboot проверяет SHA-256 и выполняет swap-move. Приложение использует тот же `flash_map_backend.c` и штатный `bootutil_public.c`. Модуль `app/fw_update.c` принимает образ, проверяет CRC32 и передаёт MCUboot решение о пробном запуске.

Активный слот начинается с `0x0800C000`. Второй слот занимает `0x08040000–0x080737FF`. Максимальная длина файла образа `0x32800` байт, две страницы трейлера начинаются с `0x08072800`. Страница калибровки энкодеров начинается с `0x0807F800`. Стирание и калибровка используют один контроллер Flash, поэтому обновление отклоняет BEGIN во время калибровки, а активное обновление снимает признак связи у прикладного управления.

FC04 читает 16 регистров с `0x0100`. По порядку идут состояние, ошибка, смещение в двух словах, версия активного образа в пяти словах, флаги, версия второго образа в пяти словах и версия блока 1. В 32-битных значениях младшее слово идёт первым. Версия содержит major, minor, revision и два слова build. Флаги `1`, `2`, `4`, `8` означают наличие первичного образа, подтверждение, наличие вторичного и активную пробную загрузку.

FC16 с `0x0100` содержит номер операции, два слова аргумента и число байт. Операции BEGIN/DATA/VERIFY/INSTALL/ROLLBACK/ABORT имеют номера 1–6. DATA несёт от 8 до 232 байт, кратных 8. Утилита дополняет только последний кусок байтами FF и считает CRC32 по исходному файлу. Ответ DATA отправляется после записи. Состояния IDLE/ERASING/RECEIVING/VERIFIED/ERROR/VERIFYING/REBOOT_PENDING имеют номера 0–6.

Пробный образ подтверждается после 30 секунд непрерывного признака связи. По истечении 120 секунд с начала пробного запуска сброс возвращает предыдущий образ. PC-клиент читает статус во время подтверждения, восстанавливает связь после сброса и проверяет целевую версию.

Build Debug создаёт образ MCUboot в двух форматах. `USV_stm32-mcuboot.hex` идёт в Run и начинается с `0x0800C000`. `USV_stm32-mcuboot.bin` заканчивается сразу после TLV SHA-256 и передаётся через UART. Указанная в `MCUBOOT_IMAGE_VERSION` версия по умолчанию `1.1.3+0`.
